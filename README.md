## ⚡ Core Engineering Philosophy

- **Zero Unnecessary Bloat**: Prefer native web standards (ES2026, CSS `@layer`, Native Dialog/Popover APIs) whenever possible to maximize performance and minimize bundle payloads.
- **Design-Driven Development**: Every interface is crafted with mathematical precision, consistent visual rhythms, fluid scaling (`clamp()`), and accessible color contrast.
- **Robust State Architecture**: Unidirectional data flow, isolated component error boundaries, and reactive database subscriptions ensure reliable applications under scale.
